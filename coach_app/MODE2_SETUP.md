Coach retains the original dark navy/cyan palette, stats cards and circular AI companion. It has two Mode 2 choices: Hold RMB and Proximity magnet. The old single-click ray correction is removed; firing uses the original gun path.

Proximity magnet automatically applies bounded smooth camera assistance when a visible, unoccluded, hittable head enters the angular zone around the crosshair. Default radius 3 degrees; Coach slider 0.5–10 degrees. It needs neither RMB nor a shot. Switching radius/mode stops assistance; press Start again. Exiting the zone stops corrections. All focus/session/menu/pause/F8/ESC gates remain.

Coach displays correction acquisition count, last entry error, signed actual yaw/pitch correction, and remaining error in degrees. These are assist measurements, not a sensitivity conversion or unassisted skill score. Each session JSON now contains aim_corrections with target, mode, entry error, applied angles and residual. Each acquisition is one record, updated during tracking, at most 10000 records per session. New sessions reset measurements. Nebius receives the optional records through the existing report input and is instructed to distinguish assisted statistics.

Coach Stop normally arrives in the next ~100ms poll; remote lease expiry is 600ms. No automatic firing, capture, YOLO, Quartz or Accessibility requirement. Local build: build/Mode2/AI-Aim-Trainer.app. Previous local rollback commit: 47618a9.

Coach supports Mode 1 Nebius session reports and Mode 2 Unity internal camera assistance.

See MODE2_SETUP.md for controls, safety behavior and rollback. Launch with .venv/bin/python -m coach_app.main from the project root. Unity uses the existing loopback Coach server on port 8765. No screen capture or accessibility permissions are required. Legacy tools and data are quarantined under legacy_mode2.

# Coach controls and measurements

Select Mode 1 for session reports or Mode 2 for Unity camera assistance. Start/Stop and the assist controls live in the floating Coach window.

- **Hold RMB:** while assistance is armed, hold the right mouse button for bounded, smooth head alignment; release to stop.
- **Proximity magnet:** a valid, visible head must be within the configured angular zone, and raw mouse input must stay still for 150 ms before assistance starts. Mouse movement interrupts proximity assistance.
- **Assist zone:** 0.5–10 degrees (default 3). Changing zone or mode stops assistance; press Start again.
- **Assist speed:** 5–180 degrees/second (default 65). Live changes do not rearm a stopped mode.
- **Stop, F8, Escape:** stop assistance. Game focus, active-session and menu/pause checks also gate assistance. Firing is always manual.

Each completed assistance segment is exported in the session's `aim_corrections` records, including entry gap, applied rotation/path, remaining gap, duration, settings and end reason. Coach displays session averages, not just the latest correction. Remaining gap is measured when assistance stops, not at the shot; assisted hit rate does not measure unaided skill.

Statistics and their explanations are generated by code. AI selects only a validated exercise offered by the program; rejected AI text is never displayed as measured evidence. No screen recording, YOLO, Quartz or Accessibility permission is needed.

Use **API key** to enter your own Nebius key. It is saved outside the app in this Mac's login Keychain. The entry is masked and never prefilled with an existing key. Saving replaces the Coach key on that Mac; cancelling leaves it unchanged. Saving does not make an API test request. Reopen a session to request advice.
